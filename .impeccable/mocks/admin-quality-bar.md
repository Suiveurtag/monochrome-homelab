# QUALITY BAR — Monochrome operator console

- Thesis: a calm, exact control room embedded in the music application, not a generic SaaS analytics dashboard.
- Palette: near-black and charcoal token surfaces, white/grey type, semantic green for health and restrained red only for destructive outcomes.
- Materials: matte ink fields, one-pixel rules, compact native controls, flat rows, and shallow overlays; no glass, gradients, glow, or decorative cards.
- Type: the existing Monochrome workhorse sans, compact operational labels, tabular counts, and sentence-case copy.
- Composition-independent craft bar: deliberate density, consistent hairline alignment, clear selection and focus states, tactile but quiet controls, immediate system feedback, and motion that explains state changes.
- Native devices to preserve: local section rail, status ribbon, metric strip, member ledger, attached inspector, switch ledgers, and sticky save state.
- Responsive bar: retain the information hierarchy in constrained app columns and on phones; allow the local rail to become a horizontal index, progressively collapse table metadata, and never introduce page-level overflow.
- Accessibility bar: semantic landmarks and labels, non-color state language, visible keyboard focus, comfortable targets, and a complete reduced-motion path.
